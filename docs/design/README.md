# Inkwell 界面设计图规范

应用界面设计图用于讨论界面布局、操作入口和状态变化。版式以[阅读状态栏与章节页眉](2026-11-reader-status-bar.png)为参考，应用画面遵循 [Inkwell UI 统一层](../../CLAUDE.md#ui-统一层硬规则)。

## 版式

- 用浅灰画布 `#F2F3F6`、深色标题 `#191B21` 和次要文字 `#555D69`。页首左对齐放「Inkwell 墨水」与功能名。阅读纸色影响判断时，在页首右侧显示色块和纸色名。
- 每列依次放状态名称、一行变化或操作路径、手机画面。对照画面等宽、等高、顶部对齐，使用同一设备轮廓和比例。参考图的三列画布为 `1360 × 1024`，手机示意为 `352 × 760`，配深色窄边框。
- 同一个对照组使用相同主题、示例正文和阅读位置。对照文字只说明画面中的差异或入口，留出空间给界面本身。

## 应用画面

- 以当前应用的 Miuix 组件和 [Dimens](../../app/src/main/kotlin/com/radium/inkwell/ui/components/Dimens.kt) 为准。复用现有字级、图标、分组卡片、滑块和开关，按同一比例绘制。
- 阅读画面从 `ReaderTheme` 取纸色、正文和辅助文字色。底部面板与卡片按 `ReaderThemeScope` 的明度层次绘制，开关颜色跟随该纸色下的 Miuix 主题。
- 根据状态展示系统栏、挖孔、弹层和安全区。新控件与相邻旧控件一起展示，标出用户实际可走到的入口。正文、书名和设备信息使用可公开的示例。

## 导出与核对

- 用 `YYYY-MM-功能名.png` 命名，保存在 `docs/design/`。以两倍像素密度导出。参考图为 `2720 × 2048`。
- 按原尺寸检查小字、边距、截断和遮挡，再缩小预览，确认场景名称和主要区别仍可辨认。
