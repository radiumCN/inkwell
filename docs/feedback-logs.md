# 反馈日志

反馈附件中的 `usage-events.jsonl` 是应用主动记录的最近操作，每行一个 JSON 事件。
它独立于开发者选项中的系统日志录制；用户不必提前开启录制即可在反馈时附带最近操作。
ZIP 仍走现有私有上传协议，服务端不需要变更。

## 已记录范围

| 事件 | 用途 |
| --- | --- |
| `app.start / foreground / background / crash` | 区分应用会话、前后台和崩溃。崩溃记录异常类型及最多 8 个栈帧，不记录异常消息 |
| `navigation.go / back / pop_to / visible` | 页面跳转请求与当前页面，记录稳定页面名及栈深，不记录路由参数 |
| `book.open / open.ignored` | 打开书籍及被重复打开保护拦截的操作 |
| `ui.click` | 阅读菜单的目录、换源、自动翻页、设置，以及搜索、刷新、同步、提交反馈等关键操作 |
| `reader.input` | 点按、滑动松手、动画开始、提交、回滚、中断、边界拦截、读屏翻页、滚动跨页 |
| `reader.input.volume / auto / menu_swipe` | 音量键、自动翻页和菜单滑动的程序化请求 |
| `reader.flip.commit_requested / blocked / page.shown` | 翻页提交请求、无法翻页的原因及最终显示的章节、页码和字符偏移 |
| `reader.chapter.request / seek / chapter.load.start / chapter.load.end / chapter.load.failed` | 跳章、拖动进度及章节加载（含预取）的结果与耗时 |
| `reader.session.load.* / menu.toggle / sheet / settings.apply / source.* / auto_flip.*` | 进书、阅读面板、设置、换源与自动翻页状态 |
| `bookshelf.* / search.* / feedback.*` | 导入和移除数量、搜索耗时及失败数量、日志选项和反馈结果，不记录输入值 |

章节、页码和字符偏移从 **0** 开始。`page.shown` 是最终位置记录；一次 `TAP` 或 `SWIPE_RELEASE`
并不等于翻页成功，需要结合 `COMMIT`、`page.shown` 或 `blocked` 判断。
滚动阅读只在跨越分页边界时记录，不逐帧记录位移。未接入的按钮、系统手势不会自动成为业务操作事件。

## 时间与完整性

- `time`：UTC 时间；`elapsed_ms`：本次进程启动后的单调时间；`session`：本次进程的随机会话编号。
- `seq`：会话内的事件编号；`screen`：当前页面；`fields`：有限长度的诊断字段。
- 写入走有界后台队列，不在点击/翻页线程上写文件，不在绘制或动画逐帧回调中打日志。
- 本地 4 个文件轮转，每个最多 256KiB，总计最多约 1MiB；过期记录在写入或导出时清理，保留最多 7 天。
- 反馈导出最近最多 512KiB 的完整事件行，导出前先排空此前已入队的事件。较旧系统日志仅取最近 3 天的文件尾部。
- 最后一条 `log.snapshot` 标记这是有界历史，并给出本次进程累计的 `dropped`（队列满）和 `write_failures`。
- 它用于还原最近的关键路径，无法保证所有操作的完整历史。容量轮转、队列溢出、系统强杀或断电可能丢失记录。
- 上次写入被中断的半条记录会在再次写入前修复；ZIP 只导出完整事件行。

## 隐私与保存

操作事件不记录正文、搜索词、表单输入、书名、网页地址、文件路径或触点坐标。
书籍和来源仅使用会话内摘要关联，无法跨会话追踪；敏感字段和常见凭据在写入前屏蔽。
系统 logcat 与历史运行日志仍可能包含书名等信息，导出前会做基础脱敏。

本地文件位于 `filesDir/logs/usage/`，排除在云备份和设备迁移之外，开发者选项的“清除日志”同时清除操作记录。
只有用户主动勾选附带日志时才上传；上传后私有保存 30 天。公开 issue 只保留提交编号，开发者按编号到服务器读取 ZIP。
