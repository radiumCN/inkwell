# Inkwell 推广图与发布文案规范

用于制作 Inkwell Android 版的发布封面、功能图、横幅、更新一览和配套推广文案。沿用既有的清爽纸感，图文围绕本版用户能感知的变化展开。

## 确定本版卖点

1. 确认目标版本和渠道。已经打标的版本以 Git tag 注解和对应构建为准。准备中的版本用本轮已合入的改动和待发布构建核对。版本标签与目标一致，内测包标明 beta。
2. 选一个主卖点放在封面和正文开头，再挑两到四个值得展示的变化。把实现细节换成阅读场景里的结果，例如「拖动时正文实时预览」，并用目标构建确认操作路径、适用范围和限制。
3. 宣传图、渠道文案和更新一览共用这份卖点清单。分别核对功能名、版本号、适用范围和下载入口。GitHub Release 正文沿用仓库现有的标注 tag 流程。 [发布流程](../../CLAUDE.md#发布流程)

## 设计与出图

| 图件 | 画布 | 内容 |
| --- | --- | --- |
| 竖版封面 | 1080 × 1440 px | 品牌名、版本、一句主标题和最能说明卖点的应用画面 |
| 功能图 | 1080 × 1440 px | 一张图讲一个体验，用截图或局部放大说明动作和结果 |
| 横版横幅 | 1920 × 1080 px | 延续封面的主题，采用横版构图，留出版本与下载信息的位置 |
| 更新一览 | 1080 × 1440 px | 按功能分组，短标题配一句说明，附 Android 下载入口 |

- 沿用浅色纸底、深色主文字和适量强调色。轻玻璃、连续圆角和浅阴影用来区隔内容，版本色可随主题换。界面文字优先用 MiSans，中文后备可用 Noto Sans SC。阅读示例可用 Noto Serif SC。
- 用目标构建的截图展示真实操作。需要重绘界面时，按目标构建核对控件和文案，并标「界面示意」。演示使用可公开的示例书和账号数据，裁掉与功能无关的个人信息。
- 沿用 HTML/CSS 模板。共用配色、字级和样机样式放在共用 CSS，按版本调整内容和构图。截图、图标等资源都通过相对路径引用。
- 通过 Playwright Chromium 在字体加载后截取 `.canvas`，按 2 倍导出 PNG。竖图成品为 2160 × 2880 px，横图为 3840 × 2160 px。字体来源和替代字体随模板记下，换电脑出图时检查换行和字重。

## 推广文案

| 物料 | 写法 |
| --- | --- |
| 标题 | 给出两到三个备选。包含「Inkwell 墨水」和版本，主标题直接写用户能感知的变化 |
| 长版 · 酷安和小红书 | 用一句读者场景开头，每段讲一个卖点。按需补充操作路径、使用条件和其他更新，文末附下载地址 |
| 短版 · 微博、朋友圈和读书群 | 保留一段正文，交代版本和两到三个最重要的亮点，附下载地址 |

- 用克制、具体的中文。动作用应用里的叫法，路径写成「意见反馈 → 反馈记录」。对外统一用「来源」，可沿用产品已有的「换源」「订阅源」等词。 [界面用词](../../CLAUDE.md#界面用词不出现书源)
- 产品说明可写「免费开源、无广告，本地阅读无需注册」。Android 与网页版的条件分别说明。兼容范围、同步能力和修复效果按该版本实际表现表述。
- Android 下载为 <https://book.skylark.run/android>，开源地址为 <https://github.com/radiumCN/inkwell>。面向已安装用户时，可补充「设置 → 检查更新」。系统要求以目标构建为准。

### 参考写法

以下三条取材于 `0.6.2` 正式版，同一卖点分别用在封面、正文和短版。

- 封面「边读边调，翻页更跟手」
- 长版「读到一半想把字调大一点，或者把屏幕调暗一点？现在拖动滑杆就能边调边看。」
- 短版「Inkwell 墨水 0.6.2 正式版｜边读边调，翻页更跟手。拖动滑杆可实时预览字号和亮度，仿真回翻时卷角跟着手指走。」

## 保存与跨电脑复用

- 从下一次整理物料起，把可公开的 HTML、CSS、JS、必要截图、图标、渲染脚本和 `copy.txt` 放进 `docs/promo/v<版本>/`。版本目录内用 `01-cover.html`、`02-主题.html` 等编号确定展示顺序，`out/` 用于 PNG 成品。提交前让模板从自身目录通过相对路径读齐资源，避免依赖本机绝对路径或 Git 忽略目录。
- 本机 `0.6.2` 的历史素材在 `tmp/promo/`，常用入口为 `61-v062-cover.html` 到 `66-v062-changelog.html`、`copy-v062.txt` 和 `render.py`。模板还引用 `tmp/reader-settings-phone/` 与 `tmp/phone-curl-fixed/` 内的截图。归档时挑选实际引用的公开素材，更新引用路径。
- 新电脑可用 `python -m pip install playwright` 和 `python -m playwright install chromium` 安装渲染依赖。在模板目录运行 `python render.py 01 02` 可按编号选择图件，省略编号可导出全部。历史版在 `tmp/promo/` 中运行 `python render.py 61 62 63 64 65 66` 即可选择 `0.6.2` 这组。
- 交付前检查 PNG 尺寸、字体、缩略图可读性和截图裁切，再从图文两处复核版本、功能入口与下载地址。跨电脑归档时，在仅有仓库文件的目录里至少重出一张封面，确认依赖齐全。
